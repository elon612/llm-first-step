# my-answers — 每章检查题的答案

问题在 [chapter-checks.md](../chapter-checks.md)。每学完一章，合上书，在对应文件里用自己的话写答案，然后提交。

规则：

- **合上书写**。写不出说明那一章没过，回去重写代码，不要抄书凑字数。
- **不要复制公式**。合格线是能用自己的话讲清机制（见 Ch 3 的 Q/K/V 粒度要求）。
- **写完让 LLM 批改**。把整篇答案贴给模型，让它指出含糊和错误的地方，改完再提交。
- 一章一个提交。git 历史就是你的进度条。
